All endpoints are publicly accessible. No authentication required.

Endpoints

GET /api/check

Analyze a URL or domain for phishing indicators. Returns a risk score, verdict, and detailed threat flags.

Parameter Type Required Description
url string required* Full URL to analyze (e.g. http://cbn-verify.com/update)
domain string optional* Domain only (e.g. gtbank-ng.com). Use instead of url.

* Provide either url or domain — at least one is required.

Example Request
GET /api/check?url=cbn-nigeria-verify.com/update-bvn
Example Response
{
  "query": "cbn-nigeria-verify.com/update-bvn",
  "threat_detected": true,
  "risk_score": 100,
  "verdict": "PHISHING",
  "flags": [
    "African brand impersonation detected: Central Bank of Nigeria (cbn.gov.ng)",

  ],
  "checked_at": "2026-07-23T20:50:11.314745+00:00",
  "powered_by": "PhishRadar Africa Threat Intelligence"
}

Code Examples

Python
import requests

response = requests.get(
    'https://phishradar.onrender.com/api/check',
    params={'url': 'cbn-nigeria-verify.com/update-bvn'}
)
data = response.json()
print(data['verdict'])      # PHISHING
print(data['risk_score'])   # 100
print(data['flags'])        # List of threat indicators
JavaScript
fetch('https://phishradar.onrender.com/api/check?url=suspicious-site.com')
  .then(res => res.json())
  .then(data => {
    console.log(data.verdict);     // PHISHING / SUSPICIOUS / SAFE
    console.log(data.risk_score);  // 0-100
    console.log(data.flags);       // Threat details
  });
